# Anatoly Tsar — сайт тату-мастера

Одностраничная визитка: https://arbacat.github.io/tatto_Anatoly_page/

## Запуск

- Локально: `python3 -m http.server`, открыть http://localhost:8000.
- Всё в одном HTML-файле (удобно переслать): `python3 build.py . ../anatoly.html`.

## Работы

Анатолий добавляет работы сам через админку [Pages CMS](https://app.pagescms.org): «Работы» → добавить → фото, название, стиль → сохранить. Через 2–3 минуты работа на сайте. Первая в списке показывается первой.

Как устроено:

- Список — `data/works.json`, фото — `assets/works/`, поля админки — `.pages.yml`.
- После каждого сохранения `.github/workflows/works.yml` запускает `scripts/build_works.py`. Скрипт приводит новые фото в порядок (поворот, JPEG до 2560 px, без EXIF и GPS), делает уменьшенные копии в `assets/works/sizes/` и обновляет список работ в `index.html`. Этот список руками не править — перезапишется.
- Если в списке ошибка (нет фото или названия), сайт не меняется, а GitHub присылает письмо.
- Без админки: `pip install pillow pillow-heif`, поправить `data/works.json`, запустить `python3 scripts/build_works.py`.

### Подключить админку (один раз)

1. Войти на [app.pagescms.org](https://app.pagescms.org) через GitHub и установить приложение Pages CMS на репозиторий `tatto_Anatoly_page`.
2. В Pages CMS пригласить Анатолия по почте (Collaborators). Аккаунт на GitHub ему не нужен.
3. Добавить пробную работу и проверить, что во вкладке Actions прошёл запуск «Portfolio».
4. Попросить Анатолия выключить геолокацию для камеры (iPhone: Настройки → Конфиденциальность → Службы геолокации → Камера → Никогда). Иначе координаты студии останутся в истории репозитория: он публичный, а скрипт убирает GPS только из опубликованной копии фото.

## Публикация

GitHub Pages из ветки `main`. Если после пуша сайт не обновился: `gh api -X POST repos/ArbaCat/tatto_Anatoly_page/pages/builds`.

Свой домен:

1. У регистратора: A-записи корня на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; для `www` — CNAME на `arbacat.github.io`.
2. Settings → Pages → Custom domain, после проверки DNS включить «Enforce HTTPS».
3. Заменить старый адрес в `index.html` (canonical, og:url, og:image, JSON-LD) и обновить превью через Facebook Sharing Debugger.

## Дизайн

- Цвета, шрифты и отступы — в начале `style.css`, иконки — SVG-спрайт в начале `index.html`.
