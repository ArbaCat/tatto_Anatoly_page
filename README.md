# Anatoly Tsar — кликабельный прототип

Концепция: тёмная мастерская, фотографии крупным планом, спокойная типографика и прямой путь к консультации.

## Как посмотреть

Рядом с этой папкой находится `anatoly-prototype.html`: автономный файл со встроенными стилями, взаимодействиями и фотографиями. Откройте его в современном браузере. Интернет нужен только для перехода в Instagram; открытие письма требует настроенного почтового приложения.

В этой папке сохранена версия для дальнейшего редактирования: `index.html`, `style.css`, `app.js`, `assets/`.

## Что работает

- Адаптация для телефона и компьютера, мобильное меню.
- Пять работ: переключение на странице, полноэкранный просмотр, стрелки клавиатуры, Escape; реализован свайп в увеличенном просмотре.
- Переход от выбранной работы к консультации с сохранением названия в сообщении.
- Проверка обязательных полей, подготовка текста, копирование с ручным запасным вариантом, открытие письма в почтовом приложении.
- Раскрывающиеся ответы на вопросы.
- Отдельная кнопка консультации на мобильном после первого экрана; скрывается у контактов и при открытом диалоге.
- Небольшие анимации: последовательное появление текста первого экрана, однократное появление секций при прокрутке, плавное появление выбранных фотографий, меню и окон, отклик кнопок. Системная настройка уменьшенного движения отключает анимации; её изменение также отменяет уже начавшееся движение. Контент доступен и без анимаций.

## Полировка (24.10.2026)

- Навигация: шапка фиксированная — прозрачная над первым экраном, дальше компактная полоса с размытием; прячется при прокрутке вниз, возвращается при прокрутке вверх. Переход по якорям с собственной плавной кривой; «Práce» встаёт ровно в экран (раньше обрезались стрелки и подпись), раздел при движении вверх не уходит под шапку. Активный раздел подчёркнут в меню. Прокрутка колесом или касанием прерывает переход.
- Работы: все фотографии, подписи и счётчики лежат друг на друге заранее (фото декодированы при загрузке), листание только переключает активный слой. Новое фото проявляется поверх, старое остаётся непрозрачным под ним и гаснет следом — без провала яркости и пустого кадра. Блок подписи держит размер самого длинного варианта, поэтому кнопки и текст вокруг не прыгают; быстрые клики не обрывают переход, а разворачивают его. Стрелки клавиатуры и свайп работают и на странице, не только в просмотре.
- Ховеры: единый язык — пилюли заливаются золотом снизу, у текстовых ссылок линия «протирается», стрелки уходят в своём направлении (↓ вниз, → вправо), круглые кнопки светлеют без резкой инверсии. Ховеры включены только на устройствах с мышью, на телефоне не «залипают».
- Большая фотография: кликабельна только сама картинка (обычный курсор-лупа), а не весь чёрный экран вокруг; полоса со стрелками и подписью клики к фото не пропускает. При наведении на фото подсвечивается «Detail práce» — то же действие, названное словами. Ярлык «Zväčšiť» остался только для клавиатуры (по Tab). Ярлык-курсор, следовавший за мышью, убран: он прятал курсор, накрывал стрелки, и клик уходил в увеличение вместо листания.
- Плитки работ одной высоты, подписи на одной линии; при наведении — лёгкий зум.
- Окна закрываются с анимацией (крестик, Escape, клик по фону); переход из просмотра работы в консультацию без мигания фона. Меню закрывается, потом страница едет к разделу.
- FAQ раскрывается по высоте; нижняя кнопка на телефоне выезжает и уезжает.
- Прокрутка (по записи экрана): убраны появления блоков при прокрутке — фото и тексты больше не проявляются и не подъезжают на 14 px, они просто на месте. Ленивая загрузка картинок убрана, все изображения декодируются заранее, поэтому не «вспыхивают» при входе в экран. Шапка постоянной высоты (анимировался padding — это пересчёт раскладки на каждом кадре), прячется сразу после первого экрана и не пропускает заголовок под прозрачным логотипом; возвращается после ~50 px прокрутки вверх, мелкие рывки трекпада её не дёргают. Обработчик прокрутки больше не мерит раскладку на каждом событии. Фото первого экрана при загрузке больше не проявляется из чёрного.

Исходная версия до полировки — в папке `_before-polish/` рядом. Автономный файл пересобирается из исходников: `python3 build.py . ../anatoly-prototype.html` (из этой папки).

Форма не отправляет сообщения и не создаёт резервирование. Данные существуют только в текущей странице; серверное хранение и аналитика отсутствуют.

## Проверено

После добавления анимаций повторно проверены автономный файл через локальный HTTP, быстрое переключение работ, галерея с клавиатуры и Escape, мобильное меню, переход к разделу и открытие консультации. При ширине 390 px нет горизонтального переполнения, фотографии загрузились, ошибок JavaScript не зарегистрировано. Отдельная проверка логики подтвердила запрет запуска и отмену активных анимаций при уменьшенном движении; системная настройка в интерфейсе ОС не переключалась.

В браузере: широкий экран 1440 × 900 и мобильный 390 × 844; переходы, мобильное меню, смена работы, открытие и закрытие галереи, стрелки клавиатуры, возврат фокуса после Escape, перенос выбранной работы в форму, обязательные поля, подготовленный текст и содержимое mailto-ссылки, раскрытие FAQ. На мобильном не обнаружена горизонтальная прокрутка. Изображения загрузились, ошибок JavaScript в журнале браузера не было. Это функциональная проверка прототипа, не полный аудит доступности.

Проверка проводилась через локальный HTTP-просмотр. Автономный файл проверен на встроенные ресурсы и уникальность идентификаторов; открытие `file://` не проверялось, поскольку встроенный браузер среды запрещает этот протокол. Откройте HTML обычным браузером. Копирование зависит от разрешений браузера; предусмотрено выделение текста для ручного копирования.
